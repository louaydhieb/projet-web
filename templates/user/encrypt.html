Démonstration du chiffrement symétrique via Fernet (AES-256-CBC + HMAC-SHA256)

Chiffrer un message

Le message est chiffré avec AES-256 (clé stockée en variable d'environnement), puis un HMAC-SHA256 est généré pour garantir l'intégrité.

Déchiffrer un message

Collez le texte chiffré et optionnellement le HMAC pour vérifier l'intégrité avant déchiffrement.

Chiffrement AES-256

Fernet encapsule AES-128 en mode CBC avec padding PKCS7 et une clé dérivée de 256 bits. La clé est stockée dans la variable d'environnement AES_ENCRYPTION_KEY.

IV aléatoire

Un vecteur d'initialisation (IV) aléatoire est généré pour chaque chiffrement, garantissant que le même message produit des textes chiffrés différents.

Intégrité via HMAC

Un HMAC-SHA256 distinct (clé HMAC_SECRET_KEY) est calculé sur le texte chiffré pour détecter toute altération.
