Signature HMAC-SHA256

Démonstration de la génération et vérification d'un HMAC pour l'intégrité des données

Générer un HMAC

HMAC-SHA256 utilise une clé secrète (HMAC_SECRET_KEY) et l'algorithme SHA-256 pour créer une empreinte authentifiable.

HMAC-SHA256
Vérifier un HMAC

Vérifiez l'intégrité et l'authenticité d'un message. La comparaison résiste aux attaques temporelles via hmac.compare_digest().

HMAC Valide ✓
Le message est authentique et n'a pas été altéré.
HMAC Invalide ✗
Le message a peut-être été altéré ou la clé est différente.
Démonstration : Altération détectée
1
Générez un HMAC pour "Bonjour"
2
Modifiez le message en "Bonjour!" (ajoutez un caractère)
3
Vérifiez – le HMAC sera invalide, prouvant l'altération

Principe de fonctionnement (Python) :

import hmac, hashlib

# Génération
key = b"HMAC_SECRET_KEY"
message = b"Bonjour"
signature = hmac.new(key, message, hashlib.sha256).hexdigest()

# Vérification (résistante aux timing attacks)
is_valid = hmac.compare_digest(expected, signature)
